# Стек технологий и архитектура программы Audja (Первоначальный разбор)

Анализ состава и архитектуры приложения **Audja** (`C:\Program Files\Audja`) на основе исследования исполняемых файлов и динамических библиотек (DLL).

---

## 1. Основной язык и среда выполнения
* **Язык программирования**: **C++**
* **Компилятор / Рантайм**: Microsoft Visual C++ (MSVC toolset)
* **Системные зависимости**: `vcruntime140.dll`, `msvcp140.dll`, `concrt140.dll`

---

## 2. 3D-движок и геометрия (Core 3D Stack)
* **MeshLib Framework** (`MRMesh.dll`, `MRViewer.dll`, `MRVoxels.dll`, `MeshLibC2.dll`, `MRCommonPlugins.dll`, `MRSymbolMesh.dll`, `MRIOExtras.dll`)
  * C++ фреймворк от MeshInspector для работы с полигональными сетками (mesh), воксельным моделированием, 3D-сканированием и высокопроизводительной триангуляцией.
* **Open CASCADE Technology (OCCT)** (`TKernel.dll`, `TKBRep.dll`, `TKDESTEP.dll`, `TKGeomAlgo.dll`, `TKTopAlgo.dll` и др.)
  * Промышленное CAD-ядро для обработки твердотельной (B-Rep) геометрии, построения точных поверхностей и работы с CAD-форматами (STEP, IGES, BREP).

---

## 3. Графический интерфейс (GUI) и рендеринг
* **Dear ImGui** (`imgui.dll`) — графическая система пользовательского интерфейса (Immediate Mode GUI), широко используемая в 3D-редакторах и инженерном ПО.
* **GLFW** (`glfw3.dll`) — библиотека для создания окон, работы с контекстом OpenGL и ввода пользователя.
* **FreeType** (`freetype.dll`) — растеризация векторных шрифтов.

---

## 4. Скриптинг и плагины
* **Python 3.11** + **pybind11** (`python311.dll`, `MREmbeddedPython.dll`, `pybind11nonlimitedapi_stubs.dll`, `MRPython.dll`)
  * Встроенная интерпретируемая среда Python для написания скриптов автоматизации, плагинов и связки C++ ядер с высокоуровневой логикой.

---

## 5. Вычисления и производительность
* **NVIDIA CUDA** (`MRCuda.dll`) — GPU-ускорение алгоритмов обработки 3D-сеток и геометрии.
* **Intel OneAPI TBB** (`tbb12.dll`) — библиотека параллельного программирования для оптимизации многопоточных вычислений на CPU.

---

## 6. Форматы данных и вспомогательные библиотеки
* **OpenVDB** (`openvdb.dll`) — хранение и манипуляция объемными воксельными структурами.
* **Assimp** (`assimp-vc143-mt.dll`) — импорт и экспорт трехмерных моделей (OBJ, FBX, GLTF, STL и т. д.).
* **GDCM / OpenCTM / E57Format** — работа со специализированными форматами (медицинский DICOM, сжатые сетки CTM, облака точек E57).
* **spdlog / fmt / jsoncpp / pugixml / libcurl** — системное логирование, форматирование строк, парсинг JSON/XML и сетевые библиотеки.
